WAZ GIF Maker Pro

A modern GIF creation tool that allows users to generate animated GIFs from images with drag-and-drop support, text overlays, and live preview. 
Built with HTML, CSS, JavaScript (gifshot) and a Python PyQt5 desktop version.

✨ Features
🖼️ Drag & drop image upload
🔄 Reorder images easily
🎞️ Create animated GIFs in seconds
📝 Add custom text overlay
🎨 Customize text color, size, and position
👀 Real-time preview animation
🌙 Dark mode support
💻 Desktop version using PyQt5 (Python)
🛠️ Technologies Used
HTML5 / CSS3
JavaScript (Vanilla)
gifshot library
Python (PyQt5 version)
Pillow (PIL)
🚀 How to Run (Web Version)
Open index.html in your browser
OR
Use Live Server in VS Code
🐍 Python Desktop Version
Install requirements:
pip install -r requirements.txt
Run app:
python gif_maker_app.py
📁 Project Structure
index.html → Main web interface
app.js → GIF logic (web version)
style.css / new-style.css → Styling
gif_maker_app.py → Desktop PyQt5 app
logo.png → Project logo
requirements.txt → Python dependencies
💡 Notes
Works fully offline in browser
Desktop version provides advanced control
Output GIF is generated locally (no server needed)
